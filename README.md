# Student Management System

A console-based Student Management System built using Java.

This project allows users to manage student records through a menu-driven program. It uses Java classes, `ArrayList`, loops, conditional statements, and file handling to store and manage student information.

## Features

- Add new students with automatic ID generation
- View all student records
- Search students by ID
- Search students by name
- Update student age
- Update student marks
- Delete student records
- Calculate average, highest, and lowest class marks
- Sort students by marks from highest to lowest
- Find the class topper
- Export student details to a text report
- Save and load student records using file handling

## Technologies Used

- **Java** — Programming language
- **ArrayList** — To store and manage student records while the program runs
- **File Handling** — To save and load student data using text files
- **VS Code** — Code editor used for development

## How to Run

1. Install the Java Development Kit (JDK).
2. Open the project folder in VS Code.
3. Open the terminal in the project folder.
4. Compile the Java files:

   ```bash
   javac Main.java Student.java
   ```

5. Run the program:

   ```bash
   java Main
   ```

**Note:** Run these commands from the project folder so the program can find `students.txt` and create `student_report.txt`.

## Project Files

- `Main.java` — Contains the main menu and student management operations.
- `Student.java` — Represents a student and stores student information.
- `students.txt` — Stores student records between program runs.
- `student_report.txt` — Contains the exported student report when generated by the program.
- `README.md` — Explains the project, its features, and how to run it.
